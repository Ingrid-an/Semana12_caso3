# Reflexión individual – Josué

Durante el desarrollo del Caso 3, pude reforzar mis conocimientos sobre el funcionamiento de Django, especialmente en la configuración del proyecto y el uso de middleware. Comprendí la importancia de implementar mecanismos de auditoría que permitan registrar las acciones realizadas por los usuarios, identificando quién efectuó una modificación, qué ruta fue afectada y mediante qué método HTTP se realizó la solicitud.

Asimismo, esta práctica me permitió familiarizarme con el trabajo colaborativo utilizando Git y GitHub, mediante la clonación de repositorios, creación de ramas independientes y registro de cambios mediante commits. Considero que trabajar de esta manera facilita la organización del código, evita modificar directamente el trabajo de otros integrantes y permite mantener un mejor control de las contribuciones individuales dentro de un proyecto de desarrollo web.
